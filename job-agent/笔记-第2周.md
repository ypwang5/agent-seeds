# 第 2 周笔记：深度准备主流程（LangGraph）

## 一句话本质
**Agent 的每一步输出都要"可核对"**：差距分析引用简历行、调研事实引用搜索链接、改写引用原文；程序核对 + 模型复核 + 人工兜底，三道关。

## 流程图

```
解析 JD ─┬→ 差距分析 ─┬→ 简历改写 + 两层校验 ─有问题→ 人工确认(interrupt) ─┐
         └→ 公司调研 ─┘                    └─全部通过──────────────────────┴→ 面试题 → 报告
```

## 新概念

| 概念 | 是什么 | 本项目里怎么用 |
|---|---|---|
| StateGraph | 节点 + 连线，所有节点共享一份状态（字典） | `prep_graph.py`，7 个节点 |
| 并行分支 | 一个节点连出两条边，下一步两个节点同时跑；`add_edge([a, b], c)` 等两个都完成 | 差距分析和公司调研并行 |
| reducer | 状态字段的合并规则。`Annotated[list, operator.add]` 表示多个节点的结果拼接，而不是覆盖 | `problems` 字段，并行节点各自追加 |
| interrupt | 节点中途暂停，把问题交给人；用 `Command(resume=答案)` 继续 | 改写没通过校验时，让你采纳 / 修改 / 拒绝 |
| checkpointer | 每步存档，用 thread_id 区分任务；interrupt 必须搭配它 | SQLite 文件，命令行退出后用 `--thread` 接着跑 |
| create_agent | LangChain 1.x 的 ReAct Agent，本身就是一个编译好的图，可以当子图用 | 公司调研：搜索 → 读 → 再搜 |
| middleware | 给 Agent 加功能的插件 | `ToolCallLimitMiddleware` 限制最多搜 6 次 |

## 评测结果

| 评测 | 结果 |
|---|---|
| 防编造（24 条人工样本：14 条编造覆盖 7 种手法，10 条诚实改写） | v4-pro 复核：**漏检 0 / 14，误报 0 / 10**；flash 复核：漏检 0，误报 2 |
| 其中程序检查单独 | 抓到 7 / 14（数字、技术名、"主导"类词）；范围扩大、新增成果只能靠模型 |
| 差距分析引用核对 | 8 个 JD 共 196 条引用，修正核对规则后误报 0 |
| 差距分析区分度 | C++ 终端岗 50%，字蒙（贴合）93%，能拉开差距 |
| 端到端（命令行，3 个 JD） | 全部跑通；中断后 `--thread` 恢复，前面的步骤不重跑 |
| 离线测试 | 22 个全部通过 |

## 实测发现的问题和处理

| 发现 | 处理 / 教训 |
|---|---|
| 差距分析的"依据"是摘录（带省略号、跨行），用整行相似度核对，误报一堆 | 新写 `check_quotes`：按片段算覆盖率。**核对规则要和输出形态匹配** |
| PDF 在句子中间断行，模型常把跨行句子只标一行 | 核对范围向两侧各扩 1 行 |
| 字蒙 JD 判 100%，"沟通顺畅"也判命中 | 提示词加"从严"规则：软素质最多判"部分"，降到 93% |
| 改写把"大模型"换成"LLM"被判新增技术 | 加同义词表 |
| 改写把简历别处的真实事实拼进来（如 OCR） | 不算编造但不合规，提示"简历其他位置有，属于跨条目拼接"，让人决定 |
| 模型偶尔原样返回不改的条目 | 程序过滤 |
| 在主提示词里加规则想纠正"猎头代招"被当成用工线索，没用，还引入新错误 | 撤回。**改提示词要靠评测验证，不能凭感觉** |
| `✓`、`✔` 在 Windows 控制台（GBK）打印报错 | 改用中文"对/错""完成" |
| 隐私：存档里要不要放简历 | 进图前先脱敏，存档里只有占位符；恢复时重新脱敏同一份文件得到同样映射，最后在本机还原 |

## 已知局限（留给第 3 周以后）

| 局限 | 想法 |
|---|---|
| 模型复核放过了"具备 AI 应用开发实战经验"这类空泛总结句 | 加一类"新增总结性断言"样本进评测，再调复核提示词 |
| 改写的 `original` 偶尔只截了 PDF 断行后的半句 | 让改写也引用整条 bullet（用第 1 周的简历解析结果） |
| 公司调研只测了智谱搜索 | 有 Tavily Key 后对比 5 家公司 |
| 面试题质量只看了 2 份 | 自己真实面试时记录"押中率" |

## 常用命令（在 job-agent 目录下）

| 做什么 | 命令 |
|---|---|
| 深度准备 | `uv run job-prep --resume 简历.pdf --jd JD.txt` |
| 中断后接着跑 | `uv run job-prep --resume 简历.pdf --jd JD.txt --thread 任务编号` |
| 单独调研一家公司 | `uv run python -m job_agent.job.research 公司名` |
| 差距分析评测 | `uv run python evals/run_gap_eval.py` |
| 防编造评测 | `uv run python evals/run_fabrication_eval.py` |
| 切换搜索服务 | `$env:JOB_SEARCH = "tavily"`（需要 `.env` 里有 `TAVILY_API_KEY`） |

报告输出在 `prep_out/`（含还原后的个人信息，已加入 .gitignore）。
